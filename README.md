# 🎭 Sistema de Venta de Entradas - Teatro Moro

Este proyecto es un sistema de consola en Java para gestionar la venta de entradas en el Teatro Moro. Permite seleccionar zonas, asientos, aplicar descuentos y visualizar un resumen de cada compra.

---

## 📌 Funcionalidades

- Mostrar plano del teatro con disponibilidad de asientos.
- Comprar entradas en 4 zonas distintas:
  - Palco A
  - Palco B
  - Platea Alta
  - Platea Baja
- Aplicar descuentos:
  - 15% para personas de la tercera edad (60+)
  - 10% para estudiantes (confirmación manual)
- Validación de entradas y asientos ocupados.
- Voucher acumulativo con resumen de todas las entradas compradas.
